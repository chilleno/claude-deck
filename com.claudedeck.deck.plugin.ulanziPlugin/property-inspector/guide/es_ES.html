Claude Deck

Claude Deck muestra en el deck lo que están haciendo tus sesiones de Claude Code: cuál está trabajando, cuál te está preguntando algo y cuánto contexto queda. Además puedes responder preguntas y ejecutar /compact o /clear sin tocar el teclado.

Necesitas: macOS, Ulanzi Studio y el CLI Claude Code de Anthropic. Claude Deck es un complemento de Claude Code: por sí solo no tiene nada que mostrar. https://docs.claude.com/en/docs/claude-code/setup

Configuración

1. Instala Claude Code

Claude Code es la herramienta de línea de comandos de Anthropic para Claude. Sigue las instrucciones oficiales de instalación y ejecuta claude una vez en el terminal para que cree su configuración.

2. Activa el seguimiento de Claude

Arrastra cualquier acción de Claude Deck a una tecla y abre su panel de ajustes. La lista de configuración muestra lo que falta; pulsa Activar seguimiento de Claude. Esto añade los hooks a tu configuración de Claude Code (se guarda antes una copia de seguridad) para que el deck vea el estado de las sesiones. Reinicia las sesiones de claude que ya estuvieran abiertas.

3. Permite el control del terminal

Elige tu terminal (iTerm2 o Terminal.app) en el panel, pulsa Comprobar acceso al terminal y acepta el aviso de macOS. Responderlo ahora evita que luego una tecla parezca no hacer nada. Si lo rechazaste antes: Ajustes del Sistema → Privacidad y seguridad → Automatización → Ulanzi Studio.

4. Opcional: la pantalla grande

Pulsa una vez la tecla Configurar Pantalla para poner la pantalla de sesión de Claude en la tecla grande. Ulanzi Studio se reinicia solo para aplicarlo (unos 15 segundos). Vuelve a pulsarla para devolver la tecla grande al widget integrado.

Qué hace cada tecla

Mascota ClaudeEstado en vivo de Claude Code: programando, preguntando o inactivo. Pulsa para ir a la sesión que te necesita. Icono gris = ninguna sesión de Claude Code detectada.
Siguiente OpciónRecorre las opciones que Claude está preguntando (se muestran en la tecla grande). Icono gris = ninguna sesión de Claude Code detectada.
Confirmar OpciónResponde a Claude con la opción mostrada en la tecla grande. Icono gris = ninguna sesión de Claude Code detectada.
Configurar PantallaAlterna el estado de Claude en la pantalla grande. Pulsar = automático (Studio se reinicia solo).
Cambiar SesiónCambia qué sesión de Claude muestra la pantalla grande (en un sentido, vuelve al inicio). Icono gris = ninguna sesión de Claude Code detectada.
Claude CompactCompacta el contexto de la sesión Claude principal. Pulsa una vez para confirmar (ojos) y de nuevo para ejecutar /compact. Icono gris = ninguna sesión de Claude Code detectada.
Pantalla de SesiónLa pantalla grande: nombre de sesión, estado y selector de preguntas.
Claude ClearBorra el historial de conversación de la sesión Claude principal. Pulsa una vez para confirmar (ojos) y de nuevo para ejecutar /clear. Icono gris = ninguna sesión de Claude Code detectada.

Qué significan los iconos

  • En color — hay una sesión de Claude Code en seguimiento.
  • En blanco y negro — no hay ninguna sesión activa ahora mismo. Abre una y las teclas volverán a la vida.
  • En blanco y negro con un punto ámbar — Claude Deck aún está sin configurar: abre el panel de ajustes de cualquier tecla y completa la lista.

Si algo no funciona

Las teclas siguen grises aunque claude esté abierto

Los hooks se leen al iniciar la sesión, así que las sesiones que ya estaban abiertas cuando activaste el seguimiento no informan de nada. Reinícialas. Si sigue igual, abre el panel y revisa la lista de configuración.

Pulso una tecla y no pasa nada

Normalmente es macOS bloqueando el control del terminal. Pulsa Comprobar acceso al terminal en el panel; si aparece bloqueado, permite Ulanzi Studio en Ajustes del Sistema → Privacidad y seguridad → Automatización.

Las preguntas no aparecen en la tecla grande

Las preguntas de selección múltiple no se pueden responder desde el deck: la tecla te lo indica y te lleva al terminal. Todo lo demás aparece en la tecla grande en uno o dos segundos.

La pantalla grande volvió al widget integrado

Ulanzi Studio reescribe esa ranura al editar la página. Pulsa otra vez Configurar Pantalla y deja que Studio se reinicie.
