Claude Deck

Claude Deck shows what your Claude Code sessions are doing, right on the deck: which one is working, which one is asking you something, how much context is left — and it lets you answer questions and run /compact or /clear without touching the keyboard.

You need: macOS, Ulanzi Studio, and Anthropic's Claude Code CLI. Claude Deck is a companion for Claude Code — on its own it has nothing to show. https://docs.claude.com/en/docs/claude-code/setup

Setting up

1. Install Claude Code

Claude Code is Anthropic's command-line tool for Claude. Follow the official install instructions, then run claude once in a terminal so it creates its settings.

2. Turn on Claude tracking

Drag any Claude Deck action onto a key and open its settings panel. The Setup list shows what is still missing; press Enable Claude tracking. This adds hook entries to your Claude Code settings (a backup is saved first) so the deck can see session status. Restart any claude sessions that are already running.

3. Allow terminal control

Pick your terminal (iTerm2 or Terminal.app) in the panel, then press Check terminal access and accept the macOS prompt. Answering it now avoids a key that later seems to do nothing. If you refused before: System Settings → Privacy & Security → Automation → Ulanzi Studio.

4. Optional: the big screen

Press the Claude Screen Setup key once to put the Claude session display on the big key. Ulanzi Studio restarts itself to apply this (about 15 seconds). Press it again to give the big key back to the built-in widget.

What each key does

Claude PetLive Claude Code status: coding, asking, or idle. Press to jump to the session needing you. Grey icon = no Claude Code session detected.
Claude Option NextCycle through the options Claude is asking about (shown on the big key). Grey icon = no Claude Code session detected.
Claude Option OKAnswer Claude with the option currently shown on the big key. Grey icon = no Claude Code session detected.
Claude Screen SetupToggle Claude status on the big screen. Press = automatic (Studio restarts itself).
Claude Session SwitchCycle which Claude session the big screen shows (one way, wraps around). Grey icon = no Claude Code session detected.
Claude CompactCompact the top Claude session's context. Press once to confirm (eyes), press again to run /compact. Grey icon = no Claude Code session detected.
Claude Session ScreenThe big-screen display: session name, status, and the question picker.
Claude ClearWipe the top Claude session's conversation history. Press once to confirm (eyes), press again to run /clear. Grey icon = no Claude Code session detected.

What the icons mean

  • In colour — a Claude Code session is being tracked.
  • Black and white — no session is running right now. Start one and the keys come back to life.
  • Black and white with an amber dot — Claude Deck still needs setting up — open any key's settings panel and work through the Setup list.

If something doesn't work

The keys stay grey even though claude is running

The hooks are read when a session starts, so sessions that were already open when you enabled tracking don't report anything. Restart them. If it still doesn't help, open the panel and check the Setup list.

A key does nothing when I press it

That is usually macOS blocking terminal control. Press Check terminal access in the panel; if it says blocked, allow Ulanzi Studio under System Settings → Privacy & Security → Automation.

Questions don't appear on the big key

Multi-select questions can't be answered from the deck — the key says so and takes you to the terminal instead. Everything else shows up on the big key within a second or two.

The big screen went back to the built-in widget

Ulanzi Studio rewrites that slot when you edit the page. Press Claude Screen Setup again and let Studio restart.
