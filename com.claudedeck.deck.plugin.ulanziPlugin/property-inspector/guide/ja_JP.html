Claude Deck

Claude Deck は、Claude Code の各セッションの状態をデッキ上に表示します。どれが作業中か、どれが質問しているか、コンテキストの残りはどれくらいか。さらに、キーボードに触れずに質問へ回答したり /compact や /clear を実行できます。

必要なもの：macOS、Ulanzi Studio、そして Anthropic の Claude Code CLI。Claude Deck は Claude Code の補助ツールで、単体では表示するものがありません。 https://docs.claude.com/en/docs/claude-code/setup

セットアップ

1. Claude Code をインストールする

Claude Code は Anthropic が提供する Claude 用のコマンドラインツールです。公式のインストール手順に従い、ターミナルで一度 claude を実行して設定ファイルを作成してください。

2. Claude トラッキングを有効にする

Claude Deck のアクションをキーにドラッグし、設定パネルを開きます。セットアップ一覧に不足している項目が表示されるので、Claude トラッキングを有効化 を押してください。Claude Code の設定にフックが追加され（事前にバックアップを保存します）、デッキがセッション状態を取得できるようになります。すでに実行中の claude セッションは再起動してください。

3. ターミナル制御を許可する

パネルでターミナル（iTerm2 または Terminal.app）を選び、ターミナルアクセスを確認 を押して macOS の確認に許可を与えます。ここで答えておくと、後からキーが無反応に見える問題を防げます。以前に拒否した場合：システム設定 → プライバシーとセキュリティ → オートメーション → Ulanzi Studio。

4. 任意：ビッグスクリーン

スクリーン設定 キーを一度押すと、Claude のセッション表示がビッグキーに配置されます。適用のため Ulanzi Studio が自動的に再起動します（約15秒）。もう一度押すと内蔵ウィジェットに戻ります。

各キーの機能

Claude ペットClaude Code のライブ状態：コーディング中・質問中・待機中。押すと対象セッションへ移動。 アイコンがグレー = Claude Code のセッションが未検出です。
次のオプションClaude の質問オプションを切り替え（ビッグキーに表示）。 アイコンがグレー = Claude Code のセッションが未検出です。
オプション確定ビッグキーに表示中のオプションで Claude に回答。 アイコンがグレー = Claude Code のセッションが未検出です。
スクリーン設定ビッグスクリーンの Claude 表示を切り替え。押すだけで自動（Studio が自動再起動）。
セッション切替ビッグスクリーンに表示するClaudeセッションを切り替えます（一方向、最後で最初に戻る）。 アイコンがグレー = Claude Code のセッションが未検出です。
Claude コンパクト最上位の Claude セッションのコンテキストを圧縮します。1回押して確認（目）、もう1回押すと /compact を実行。 アイコンがグレー = Claude Code のセッションが未検出です。
セッション画面ビッグスクリーン表示：セッション名、状態、質問ピッカー。
Claude クリア最上位の Claude セッションの会話履歴を消去します。1回押して確認（目）、もう1回押すと /clear を実行。 アイコンがグレー = Claude Code のセッションが未検出です。

アイコンの意味

  • カラー — Claude Code のセッションを追跡中です。
  • 白黒 — 現在セッションが実行されていません。セッションを開始するとキーが動き出します。
  • 白黒＋オレンジの点 — Claude Deck のセットアップが未完了です。いずれかのキーの設定パネルを開き、一覧の項目を進めてください。

うまく動かないとき

claude を実行中なのにキーがグレーのまま

フックはセッション開始時に読み込まれるため、トラッキングを有効にした時点ですでに開いていたセッションは何も送信しません。再起動してください。それでも直らない場合はパネルのセットアップ一覧を確認してください。

キーを押しても何も起こらない

多くの場合、macOS がターミナル制御をブロックしています。パネルで ターミナルアクセスを確認 を押し、ブロックと表示されたら システム設定 → プライバシーとセキュリティ → オートメーション で Ulanzi Studio を許可してください。

質問がビッグキーに表示されない

複数選択の質問はデッキから回答できません。その場合はキーがその旨を表示し、ターミナルへ移動します。それ以外の質問は1〜2秒でビッグキーに表示されます。

ビッグスクリーンが内蔵ウィジェットに戻ってしまった

ページを編集すると Ulanzi Studio がそのスロットを書き換えます。もう一度スクリーン設定キーを押し、Studio の再起動を待ってください。

Claude Deck はオープンソースです。問題の報告とソースコードはこちら： https://github.com/chilleno/claude-deck · v2.4.0
