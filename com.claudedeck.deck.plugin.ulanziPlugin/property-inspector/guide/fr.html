Claude Deck

Claude Deck affiche sur le deck ce que font vos sessions Claude Code : laquelle travaille, laquelle vous pose une question, combien de contexte il reste. Vous pouvez aussi répondre aux questions et lancer /compact ou /clear sans toucher au clavier.

Il vous faut : macOS, Ulanzi Studio et le CLI Claude Code d'Anthropic. Claude Deck accompagne Claude Code — seul, il n'a rien à afficher. https://docs.claude.com/en/docs/claude-code/setup

Configuration

1. Installez Claude Code

Claude Code est l'outil en ligne de commande d'Anthropic pour Claude. Suivez les instructions d'installation officielles, puis lancez claude une fois dans un terminal pour qu'il crée sa configuration.

2. Activez le suivi de Claude

Glissez une action Claude Deck sur une touche et ouvrez son panneau de réglages. La liste de configuration montre ce qui manque ; appuyez sur Activer le suivi de Claude. Les hooks sont ajoutés à votre configuration Claude Code (une sauvegarde est créée d'abord) pour que le deck voie l'état des sessions. Redémarrez les sessions claude déjà ouvertes.

3. Autorisez le contrôle du terminal

Choisissez votre terminal (iTerm2 ou Terminal.app) dans le panneau, appuyez sur Vérifier l'accès au terminal et acceptez l'invite macOS. Y répondre maintenant évite une touche qui semblera inactive plus tard. Si vous aviez refusé : Réglages Système → Confidentialité et sécurité → Automatisation → Ulanzi Studio.

4. Facultatif : le grand écran

Appuyez une fois sur la touche Configurer l'écran pour afficher la session Claude sur la grande touche. Ulanzi Studio redémarre seul pour appliquer (environ 15 secondes). Appuyez de nouveau pour rendre la grande touche au widget intégré.

Ce que fait chaque touche

Mascotte ClaudeÉtat en direct de Claude Code : code, questionne ou en attente. Appuyez pour rejoindre la session qui vous attend. Icône grise = aucune session Claude Code détectée.
Option suivanteParcourez les options proposées par Claude (affichées sur la grande touche). Icône grise = aucune session Claude Code détectée.
Valider l'optionRépondez à Claude avec l'option affichée sur la grande touche. Icône grise = aucune session Claude Code détectée.
Configurer l'écranBasculez l'état Claude sur le grand écran. Appui = automatique (Studio redémarre seul).
Changer de sessionChange la session Claude affichée sur le grand écran (sens unique, revient au début). Icône grise = aucune session Claude Code détectée.
Claude CompactCompacte le contexte de la session Claude principale. Appuyez une fois pour confirmer (yeux), une seconde fois pour lancer /compact. Icône grise = aucune session Claude Code détectée.
Écran de sessionLe grand écran : nom de session, état et sélecteur de questions.
Claude ClearEfface l'historique de conversation de la session Claude principale. Appuyez une fois pour confirmer (yeux), une seconde fois pour lancer /clear. Icône grise = aucune session Claude Code détectée.

Ce que signifient les icônes

  • En couleur — une session Claude Code est suivie.
  • En noir et blanc — aucune session n'est active. Lancez-en une et les touches reprennent vie.
  • En noir et blanc avec un point ambre — Claude Deck n'est pas encore configuré — ouvrez le panneau d'une touche et suivez la liste.

Si quelque chose ne marche pas

Les touches restent grises alors que claude tourne

Les hooks sont lus au démarrage d'une session : celles déjà ouvertes quand vous avez activé le suivi ne remontent rien. Redémarrez-les. Sinon, ouvrez le panneau et vérifiez la liste de configuration.

Une touche ne fait rien

C'est en général macOS qui bloque le contrôle du terminal. Appuyez sur Vérifier l'accès au terminal ; si c'est bloqué, autorisez Ulanzi Studio dans Réglages Système → Confidentialité et sécurité → Automatisation.

Les questions n'apparaissent pas sur la grande touche

Les questions à choix multiples ne peuvent pas être traitées depuis le deck : la touche le signale et vous renvoie au terminal. Tout le reste s'affiche en une seconde ou deux.

Le grand écran est revenu au widget intégré

Ulanzi Studio réécrit cet emplacement quand vous modifiez la page. Appuyez à nouveau sur Configurer l'écran et laissez Studio redémarrer.
