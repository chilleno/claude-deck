Claude Deck

EnglishEspañolFrançaisDeutschPortuguês日本語한국어简体中文繁體中文

O Claude Deck mostra no deck o que as suas sessões do Claude Code estão a fazer: qual está a trabalhar, qual lhe está a perguntar algo e quanto contexto resta. Também responde a perguntas e executa /compact ou /clear sem tocar no teclado.

Precisa de: macOS, Ulanzi Studio e o CLI Claude Code da Anthropic. O Claude Deck acompanha o Claude Code — sozinho não tem nada para mostrar. https://docs.claude.com/en/docs/claude-code/setup

Configuração

1. Instale o Claude Code

O Claude Code é a ferramenta de linha de comandos da Anthropic para o Claude. Siga as instruções oficiais de instalação e execute claude uma vez no terminal para que crie as definições.

2. Ative a monitorização do Claude

Arraste qualquer ação do Claude Deck para uma tecla e abra o painel de definições. A lista de configuração mostra o que falta; prima Ativar monitorização do Claude. Isto adiciona os hooks às definições do Claude Code (é guardada primeiro uma cópia de segurança) para o deck ver o estado das sessões. Reinicie as sessões do claude já abertas.

3. Autorize o controlo do terminal

Escolha o seu terminal (iTerm2 ou Terminal.app) no painel, prima Verificar acesso ao terminal e aceite o pedido do macOS. Responder agora evita uma tecla que mais tarde parece não fazer nada. Se recusou antes: Definições do Sistema → Privacidade e Segurança → Automatização → Ulanzi Studio.

4. Opcional: o ecrã grande

Prima uma vez a tecla Configurar Ecrã para colocar o ecrã de sessão do Claude na tecla grande. O Ulanzi Studio reinicia sozinho para aplicar (cerca de 15 segundos). Prima novamente para devolver a tecla grande ao widget incorporado.

O que faz cada tecla

Mascote ClaudeEstado ao vivo do Claude Code: a programar, a perguntar ou parado. Prima para ir à sessão que precisa de si. Ícone cinzento = nenhuma sessão do Claude Code detetada.
Próxima OpçãoPercorra as opções que o Claude está a perguntar (mostradas na tecla grande). Ícone cinzento = nenhuma sessão do Claude Code detetada.
Confirmar OpçãoResponda ao Claude com a opção mostrada na tecla grande. Ícone cinzento = nenhuma sessão do Claude Code detetada.
Configurar EcrãAlterne o estado do Claude no ecrã grande. Premir = automático (o Studio reinicia sozinho).
Mudar SessãoAlterna qual sessão do Claude o ecrã grande mostra (um sentido, volta ao início). Ícone cinzento = nenhuma sessão do Claude Code detetada.
Claude CompactCompacta o contexto da sessão Claude principal. Prima uma vez para confirmar (olhos) e novamente para executar /compact. Ícone cinzento = nenhuma sessão do Claude Code detetada.
Ecrã de SessãoO ecrã grande: nome da sessão, estado e seletor de perguntas.
Claude ClearApaga o histórico de conversa da sessão Claude principal. Prima uma vez para confirmar (olhos) e novamente para executar /clear. Ícone cinzento = nenhuma sessão do Claude Code detetada.

O que significam os ícones

  • A cores — há uma sessão do Claude Code a ser monitorizada.
  • A preto e branco — não há nenhuma sessão ativa. Inicie uma e as teclas voltam à vida.
  • A preto e branco com um ponto âmbar — o Claude Deck ainda precisa de configuração — abra o painel de qualquer tecla e percorra a lista.

Se algo não funcionar

As teclas continuam cinzentas apesar de o claude estar a correr

Os hooks são lidos no início da sessão, por isso as sessões já abertas quando ativou a monitorização não reportam nada. Reinicie-as. Se continuar, abra o painel e veja a lista de configuração.

Primo uma tecla e não acontece nada

Normalmente é o macOS a bloquear o controlo do terminal. Prima Verificar acesso ao terminal; se indicar bloqueado, autorize o Ulanzi Studio em Definições do Sistema → Privacidade e Segurança → Automatização.

As perguntas não aparecem na tecla grande

As perguntas de seleção múltipla não podem ser respondidas pelo deck — a tecla avisa e leva-o ao terminal. Tudo o resto aparece na tecla grande em um ou dois segundos.

O ecrã grande voltou ao widget incorporado

O Ulanzi Studio reescreve esse espaço quando edita a página. Prima outra vez Configurar Ecrã e deixe o Studio reiniciar.
