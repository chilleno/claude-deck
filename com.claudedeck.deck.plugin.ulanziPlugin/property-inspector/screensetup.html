Claude status on the big screen

Press this key to toggle the big screen between Claude status and the built-in widget. Ulanzi Studio restarts itself to apply (~15 s). A backup of the page is saved automatically. If Studio removes the big-screen display after you edit the page, the key shows the loading animation — restart Studio to reapply.
